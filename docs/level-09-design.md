# 第九关：折页之城

日期：2026-09-10。用户已确认继续开发，当前不提交或推送。状态以 [开发计划](development-plan.md) 为准。

## 体验目标

两片建筑像书页一样绕黄铜铰链转动。展开左页能从入口走到中轴；在中轴收起左页，才会露出被它覆盖的下层楼梯；到侧台后展开右页，抵达出口。玩家需要理解「打开」和「收起」都可能创造道路。

本关使用真正的旋转层级，不用整体显隐模拟折叠。控制台位于固定平台，人物不能在折页上操作，避免脚下建筑旋转。纸白厚板、朱砂背面、黄铜铰链和折线屋面构成新轮廓。

## 节点、状态与边表

状态为 `{ leftOpen: false | true, rightOpen: false | true }`，初始均为 false。

| 节点 | 坐标 | 说明 |
| --- | --- | --- |
| S | [-4.75,0,0] | 入口固定台、左页外侧控制台 |
| A | [-2.5,0,0] | 左页中央，仅路径节点 |
| H | [-0.5,0,0] | 中轴固定台、左页内侧控制台 |
| D | [-2.5,-2,0] | 被左页盖住的下层楼梯底端，仅路径节点 |
| P | [0.5,-2,2] | 固定侧台、右页控制台 |
| Q | [2.25,−2,2] | 右页中央，仅路径节点 |
| E | [4.25,−2,2] | 固定出口台与光门 |

稳定可点击目标 S/H/P/E。固定边为 H–D、D–P，但只有 `leftOpen=false` 时可走；左页展开时增加 S–A、A–H；右页展开时增加 P–Q、Q–E。没有两页都展开即可绕过中轴下层的捷径。

## 折页几何与动作

- 左页铰链沿 z 轴设置在 H 西缘。收起时从水平面转到竖直面（`rotation.z=π/2`），展开为 0。板长 3.5、宽 1.1、厚 0.22，朱砂色背面让转动方向可见。
- 右页铰链沿 z 轴设置在 P 东缘。收起时向下悬垂（`rotation.z=−π/2`），展开为 0。尺寸与左页一致。
- 两个铰链均有分段黄铜轴套和半圆方向刻度。动作前平台旁有细线目标轮廓，预告折页终点，但轮廓不参与点击。
- `left` 仅在 S/H，`right` 仅在 P。标准时长 0.9 秒，减少动态效果 0.15 秒。折动期间锁定移动和其他机关，到位后一次提交道路状态。
- 左页收起后，其水平占位消失，下层楼梯露出；展开时楼梯仍作为实体存在但被页板盖住且不在边表中。右页收起时出口断开。
- 重置取消动画，恢复 S 与两页收起状态；换关释放铰链组、材质和几何。

## 标准解与恢复

1. 在 S 展开左页，沿 S–A–H 到中轴。
2. 在 H 收起左页，露出 H–D–P 下层楼梯；沿楼梯到 P。
3. 在 P 展开右页，沿 P–Q–E 抵达光门。

最少机关操作三次。S 可以反复开合左页；H 可重新展开左页返回 S；P 可反复开合右页并沿下层楼梯返回 H。任何错误顺序都可原路恢复，不使用重置作为解谜步骤。人物在 E 才结束，不能站在折页中途节点停留或操作。

## 验收

- 标准解必须经过展开左页、收起左页、展开右页；初始、错误折态和不可达目标均被拒绝。
- 四种折态的边表正确；穷举所有可达稳定状态，均能继续通关。
- 两片页板实际绕各自铰链连续转动，正反面有区分；碰撞目标随折态启用，竖直页板不提供虚假行走目标。
- 动画中状态未提前提交、输入锁定；中途重置和换关正确；减少动态效果使用短过渡。
- Chrome、Edge、DPR 2 鼠标完整通关并检查回程、人物遮挡、控件避让；旧八关回归、构建和外网隔离在阶段收尾统一验证。
- 趣味性、提示理解和首次通关节奏仍需玩家试玩，不以自动测试替代。

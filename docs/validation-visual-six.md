日期：2026-09-09。工作区：`D:\data\project\jlbg`。用户确认首关风格，并授权把其他关卡按同一风格优化。首关历史样板记录见 [视觉样板验证](validation-visual-sample.md)。

## 实现

- 六关使用同一个 `createTraveller`：衣袍、帽檐、手脚、步态、转身、淡出和柔和脚影。装饰动画遵守减少动态效果偏好，位置仍来自 Game；搭乘时与载具沿同一位置规则移动。
- 第二至第六关共享立体拱窗、分层台座、轻微倒角、桥底支撑、黄铜门框与有轮辐的手轮，使用首关的环境光/主光强度。新三关继续使用灰紫与浅粉配色。
- 第二关：塔身窗框、顶部边饰、随塔移动的导轨套环与底座。
- 第三关：立柱细饰、闸门柱脚与檐口、灯台拱窗、灯笼四角框架与提环。
- 第四关：双环补充下层环轨和连接支柱；转动时随所属内环/外环运动。
- 第五/六关：石偶增加面板、眼睛、胸前饰件、侧面雕窗与上下边饰；压板增加边圈，第六关锁销增加导向座。搭乘面仍保持平坦。
- 规则、节点坐标、碰撞拾取规则、按钮布局及字体不变。折梯的新增底梁与台座均随折梯显示和展开，收起时不参与拾取。未新增依赖或外部素材，未使用 Blender。

# 第十二关：归海之门

日期：2026-09-11。状态：正在实现。当前不提交或推送。

## 三幕目标

终章把已学机制压缩成三段连续路线，每段只突出一个关系。第一幕由旅人切换观察角进入中轴；第二幕唤醒岩灵，两者分别站上城门两翼的固定锚点后展开双桥；第三幕旅人先抵达门边，从背面固定最后一桥，再让岩灵跟上。已完成机关永久保留，不重走前一幕。

## 节点、状态和道路

状态为 `{ active, travellerNode, rockNode, view, wingsOpen, finalBridge }`。初始旅人在 S、岩灵在 R0、view=A，双桥均未展开。

| 角色 | 节点 | 道路条件 |
| --- | --- | --- |
| 旅人 | S[-7,0,0] → V[-4,0,0] → H[-5,1,1] | S-V 固定；V-H 仅 view=B，B 角投影重合 |
| 旅人 | H → TA[-2,1,1] | 固定；到 H 后允许切换岩灵 |
| 岩灵 | R0[-5,-1,4] → RP[-2,-1,4] | 固定宽路 |
| 旅人 | TA → TB[1,2,1] → TE[4,2,1] | 两人站在 TA/RP 展开城门双翼后成立 |
| 岩灵 | RP → RB[1,0,4] | 双翼展开后成立 |
| 岩灵 | RB → RE[4,2,4] | 旅人在 TE 固定最终桥后成立 |

## 动作与标准解

- `view`：仅当前角色为旅人且位于 S/V；在两个预设观察角间切换，B 角接通 V-H。
- `switch`：旅人抵达 H 后可在任何稳定节点切换角色，另一位保持原位。
- `wings`：旅人与岩灵分别站在 TA/RP，任一当前角色位于自己的锚点时可执行；完成后永久展开两翼。
- `final`：仅旅人在 TE 可执行，永久接通 RB-RE。双方分别到 TE/RE 才通关。
- 标准解：换景到 B → 旅人到 H/TA → 岩灵到 RP → 展开双翼 → 旅人先到 TE 并固定末桥 → 岩灵到 RE。

错误换景可在 S/V 改回；双翼展开前两位都能退回自己的固定路；末桥未固定时岩灵停在 RB，旅人可从 TE 返回 TB。动作和行走期间拒绝其他输入，重置恢复全部初始状态。

## 验收

1. 标准解必须使用换景、至少三次角色切换、双翼和最终桥；单个角色抵达不能结束。
2. 移动一位角色不改变另一位位置；两位未同时到锚点不能展开双翼。
3. 所有机关在动画结束时一次提交，已完成前段不因后段操作关闭。
4. 三段建筑剪影、当前角色和等待位置清楚，操作区不遮挡路线。
5. 逻辑回归、Chrome/Edge/DPR 2、重置、减少动态效果、构建和外网隔离在终章收尾统一验证。

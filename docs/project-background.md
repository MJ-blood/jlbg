# 项目背景与确认记录

记录日期：2026-09-08，已更新至三关实现与本机功能验证阶段。依据：本任务对话、项目文件检查和实际验证记录。

## 1. 要解决的问题

用户希望了解能否开发类似《纪念碑谷》的游戏，以及现有电脑是否支持、需要准备什么。讨论后明确优先采用浏览器游玩、初期本地离线；进一步明确最终 Windows 和 macOS 都能玩，开发方案必须细化到完整关卡，不能停在概念描述。

本项目参考其建筑操控与视觉错觉解谜思路。首版目标是验证一个完整的小型空间谜题；达到原作美术、叙事和关卡数量的完成度，不是当前已确认目标。

## 3. 方案演变与尚待评审的细节

- v0.1 的单个可通关关卡、柔和配色、悬空建筑、固定视角、点击行走、旋转机关、一处视错觉、重置和通关方向已获总体认可。
- v0.2「回光庭院」已批准并完成核心实现：10 个节点，同一座桥按 A→B→A 旋转两次、中央安全岛中转、双向视错觉接缝。规则详见 `level-01-design.md`，验证边界见开发计划。
- 早期曾建议 TypeScript，后已收敛为 JavaScript ES modules，总体方案已获认可；当前不计划新增 TypeScript。
- 用户已确认并完成实现：「浮阶之塔」的升降搭乘与侧廊复用，以及「借光回廊」的灯台压板与转桥组合，详见 `gameplay-expansion.md` 与 `validation-v0.3.md`。本地存档、音乐和撤销暂不列入近期范围。
- 免安装开发依赖的玩家包在 v0.2 列入双平台最终方案；共用游戏资源、分平台提供运行时和启动入口，尚未实现。
- 首批建议覆盖 Windows 11 x64 和 M 系列 Mac（macOS 14 或更新版本，实际支持以测试为准）；Intel Mac 作为后续验证候选，不默认承诺兼容。

## 5. 协作分工与约束

- 用户：确认范围、视觉偏好和计划；实际试玩并反馈操作和解谜体验。
- Codex：记录方案，批准后实现、验证、说明运行方式与已知限制。
- 原型可用代码生成简单几何体，用户不必先购买模型、学习建模或安装大型游戏引擎。
- 正式名称、故事、音效素材和发布时间均待确认；Windows/macOS 双平台目标已确认，其他设备仍未纳入首批范围，不提前承诺排期。
- 本轮按已确认范围完成第二、第三关及必要换关入口，沿用现有布局。没有更换依赖或全局工具，没有部署；接下来收集玩家理解与节奏反馈。

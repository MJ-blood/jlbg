# 三关实现与验证记录

日期：2026-09-08。范围：现有第一关回归、第二关「浮阶之塔」、第三关「借光回廊」、必要换关入口。Mac 与免开发依赖玩家包按用户要求后置。

## 1. 实际交付

- 三关均有开场、行走与机关、实际到达终点后通关、重玩。
- 第二关支持塔顶搭乘、远侧控制、侧廊视错觉、出口前 V 停靠与反向返回。
- 第三关支持灯台左右压板、两道持续门禁、两态旋转桥与中继岛回退。
- 保留原页面布局，新增右上角简洁章节选择、第三关灯台操作按钮、通关后的下一关入口。未增加存档、撤销、账号、音乐或复杂章节菜单。
- 各关数据与规则位于 levels.js，共享 Game 执行寻路和动作；每关场景独立构建，换关移除旧输入并释放几何、材质和纹理。

所有完整流程中未记录 pageerror/console error。初始直接点出口被拒绝，第三关出口门关闭时不能穿门；从门前返回中继岛、修正灯台后可继续通关。

### 接缝与几何

- 第一关原有接缝回归通过。三关在测试视口中的开放接缝投影差均小于 1 CSS px，实测为 0 或约 5.7e-14 的浮点误差。
- 第二关正向切换前 x≈4.157、切换后 x≈-0.102 的截图中人物与脚影均被柱体遮挡；已通过 V→C 反向行走验证。
- 第三关切换前 z≈-3.888、切换后 z≈-2.147 的截图中人物与脚影均被柱体遮挡；Z→H 可反向返回。
- 第二关升降中人物脚底与塔顶同步，站在 C 时保持原位；楼梯使用 24 级台阶，角色与渲染共享同一个台阶高度函数。
- 实际点击发现的第二关按钮挡住控制圆台、第三关两按钮靠得过近已调整；最终第三关两个控制按钮均为 48×48 CSS px，在 1440×900 下水平间隔约 42 px。

### 换关、重置与图形异常

- 连续按 1→2→3 轮换 11 轮，比较预热后同一关渲染器资源，未持续增长。开场几何计数分别稳定为 72/105/87，纹理为 2/1/1；活动目标标记首次显示时可各多 1 个几何。
- 灯台动画中切到第二关，等待后第二关仍保持开场初始状态；搭乘升降中重置恢复 S2/low，旧动作未继续执行。
- 多次换关后一次灯台点击仍只移动一次，没有重复事件响应。
- 模拟 WebGL2 不可用与 WebGL context lost：显示可读提示，隐藏机关控制，禁止无画面换关，提供重新加载。

## 5. 最终构建冷启动与网络边界

在 Chrome、Edge 各自全新的浏览器会话中验证最终构建：启用请求拦截以禁用 HTTP 缓存，禁止 Service Worker，并阻止本地预览源以外的全部页面资源请求。

两浏览器均完成三关正向流程、反向返回与重玩，只请求以下资源：

- http://127.0.0.1:4174/
- http://127.0.0.1:4174/assets/index-D0W2UAjX.js
- http://127.0.0.1:4174/assets/index-BikN9DhE.css

外网请求数 0，错误数 0；生产构建不暴露开发诊断接口。这证明构建版游戏资源不依赖外网，也不依赖先前浏览器缓存。

边界：本次采用浏览器级外网隔离，没有关闭整台 Windows 的网络适配器。静态服务仍由当前本机开发环境提供；无 Node 的玩家电脑、双击启动包与 Mac 均不在本次验证结论中。

## 6. 性能采样与仍需试玩的内容

Chrome 自动化浏览器、1920×1080、DPR 1，使用真实时间而非模拟时钟；分别在转桥、搭乘升降、灯台移动触发后采样 120 个 requestAnimationFrame 间隔，采样包含动作及动作结束后的静止时段。

实际渲染器报告 NVIDIA GeForce RTX 4080 / ANGLE Direct3D11。三关平均帧间隔约 16.67 ms（约 60 FPS），P95 约 16.9 ms；绘制调用数分别 73/106/88，三角形数 6472/3998/7538。这是当前环境的短时浏览器采样，不是所有设备的性能保证或完整 GPU 帧时间分析。

仍需用户实玩确认：首次能否看懂升降塔的两种用途、灯台与门的对应关系、提示是否过早、三关的节奏与难度。原计划时长仍是目标，不写成已测的首次体验时长。Mac 验证、玩家包、音乐、存档等继续后置。

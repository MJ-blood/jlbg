# 第十关：同行之桥

日期：2026-09-10。用户已确认继续开发，当前不提交或推送。状态以 [开发计划](development-plan.md) 为准。

## 体验目标

玩家交替控制旅人与岩灵，两者拥有不同道路能力。旅人走细桥并开启宽门，岩灵压住重板为旅人托起中桥；旅人在另一侧锁定中桥后，岩灵才能离开压板。最终两者都抵达各自光门。

采用单人轮流操作，没有同时实时输入。当前角色由底部「切换同行者」控制并在场景中显示光环；非当前角色保持原位。旅人沿用精修造型，岩灵采用矮宽、沉稳的独立轮廓。

## 状态、节点和道路

状态为 `{ active, travellerNode, rockNode, gateOpen, bridgeLocked }`。初始 active=traveller、travellerNode=S、rockNode=R0，两个机关均为 false。

| 角色 | 节点与坐标 | 道路条件 |
| --- | --- | --- |
| 旅人 | S[-5,1,0] → A[-2,1,0] | 固定细桥；A 有宽门机关 |
| 旅人 | A → B[1,1,0] | 岩灵在 P 或 bridgeLocked |
| 旅人 | B → TE[4,1,0] | 固定；B 有桥锁机关 |
| 岩灵 | R0[-5,-1,3] → P[-2,-1,3] | gateOpen 后可通过宽门 |
| 岩灵 | P → C[1,-1,3] → RE[4,-1,3] | bridgeLocked 后可离开重板 |

稳定目标为 S/A/B/TE/R0/P/C/RE。两个人和岩灵不能走入对方专属路线。岩灵抵达 P 时压板自动生效；离开 P 不清除已经由旅人在 B 锁定的桥。

## 动作与胜利

- `switch`：任何 idle 稳定节点均可执行，0.2 秒后切换 active，镜头不跳转，目的地光环改到新角色所在路线。
- `gate`：仅 active=traveller、位于 A 且 gateOpen=false；0.7 秒后永久抬起岩灵宽门。
- `lock`：仅 active=traveller、位于 B、rockNode=P 且 bridgeLocked=false；0.8 秒后永久落下黄铜桥锁。
- 最终条件为 travellerNode=TE 且 rockNode=RE。任一角色先到终点都不会单独结束；已到终点者仍可切换，但无需离再移动。
- 动作与行走期间拒绝切换和其他机关；重置恢复两名角色、门和桥锁。减少动态效果缩短机关动画，不取消状态提交。

## 标准解与恢复

1. 旅人 S→A，开启宽门。
2. 切换岩灵，R0→P，压住重板。
3. 切换旅人，A→B，锁住中桥，再走到 TE。
4. 切换岩灵，P→C→RE；两者会合后通关。

在门未开、压板无人或桥未锁时尝试对应道路，只显示关系提示提示，不改变状态。错误切换可立即切回；旅人在 B 锁桥前可退回 A，岩灵在 P 不能向终点走但可返回 R0。所有稳定状态均须可恢复。

## 验收

- 标准解必须包含一次开门、岩灵压板、一次锁桥以及至少三次角色切换；两名角色都到终点才完成。
- 分角色寻路、点击与目的地光环正确；移动一个角色不改变另一个位置；切换期间不插入移动。
- 门-压板-桥锁的到位提交正确，所有稳定状态可完成；中途重置、换关和减少动态效果正确。
- 两种角色轮廓和选中提示不只靠颜色区分；岩灵运动时有重量感，不复用旅人步态。
- Chrome、Edge、DPR 2 通关与回程，旧九关回归、资源释放、构建外网隔离在阶段收尾统一验证。

## 最终构建的外网独立性

最终构建分别在 Chromium 1440×900、Edge 1280×720 的全新浏览器上下文中完成六关正向流程与上述回退步骤。开启请求路由以禁用 HTTP 缓存，禁用 Service Worker，只允许 `http://127.0.0.1:4174/` 的资源。

两浏览器均只请求本机 HTML、最终 JS、最终 CSS；外网资源请求 0，脚本/控制台错误 0。正式构建中的 `window.__courtyard` 为 undefined。通关只由鼠标和页面按钮完成，结束界面逐关核对。

初次 Edge 回放使用固定的模拟等待时长，第三关出现尚未结束就检查通关的失败；改为观察公开界面的动作状态后，最终两浏览器各六关全部通过。该次失败没有计作成功，也没有通过修改游戏逻辑绕过。

此处证明游戏资源不依赖外网及旧缓存；没有关闭 Windows 网络适配器，也没有验证无 Node 的玩家电脑、Mac 或双击玩家包。

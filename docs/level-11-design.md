# 第十一关：镜中折院

日期：2026-09-10。状态：已确认方向，正在实现。当前不提交或推送。

## 体验目标

本关只控制旅人，组合第八关的现实/镜内与第九关的折页。玩家必须先在镜内展开折页完成上楼，再从高位镜门返回现实并收起同一折页，露出通往出口的背面道路。两个机制都不能省略。

## 状态、节点与道路

状态为 `{ realm, foldOpen }`，初始为现实、折页收起。镜门切换空间，折页状态在两侧共享。

| 空间 | 节点与坐标 | 道路条件 |
| --- | --- | --- |
| 现实 | S[-7,0,2] → M0[-4,0,2] | 固定入口路 |
| 现实 | M1[5,3,-1] → E[8,3,-1] | 仅折页收起时成立 |
| 镜内 | M0[-4,0,-2] → A[-1,0,-2] | 固定；A 有折页把手 |
| 镜内 | A → H[2,3,-2] | 仅折页展开时成立 |
| 镜内 | H → M1[5,3,1] | 固定高位路 |

M0 与 M1 都是固定镜门平台，任何折态都能往返。A 是镜内低位把手，M1 的现实侧有第二个把手。折页展开时提供镜内楼梯；折页收起时楼梯翻到建筑背面，成为现实高处的出口路。

## 动作、标准解与恢复

- `mirror`：只在 M0/M1 可执行，0.75 秒后切换空间，输入锁定，旅人映射到同名门台。
- `fold`：镜内 A 或现实 M1 可执行，0.9 秒后切换折态；折页不载人，A/M1 均为固定平台。
- 标准解：S → M0 → 镜内 → A → 展开 → H → M1 → 现实 → 收起 → E。
- 在 A 反复折叠、从 M1 返回镜内、或在现实 M1 再次展开都不会困住玩家。若镜内 M1 遇到收起状态，可回现实 M1 重新展开；若现实低位折态错误，可从 M0 回镜内 A 修正。

## 验收

1. 现实不能独自从 M0 上楼，镜内没有最终出口；标准解必须穿过两扇镜门并改变折页两次。
2. 状态只在动作结束时提交；动画中拒绝行走、穿镜和再次折叠，重置清除未完成动作。
3. 所有可达稳定状态无需重置即可到达出口，两个镜门保持双向映射。
4. 场景中同一折页在两侧的正反面和铰链位置一致，不能以两条无关道路的显隐代替。
5. Chrome、Edge、DPR 2、减少动态效果和旧关回归在阶段收尾验证；趣味性仍由玩家试玩判断。

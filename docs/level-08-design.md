# 第八关：镜海回廊

日期：2026-09-09。新篇章方向与继续推进已确认。状态以 [开发计划](development-plan.md) 为准。

## 目标与边界

现实无法沿残阶上楼，镜内没有终点。旅人通过低位镜门进入镜内，爬上完整楼梯，平移屏风打开高位镜门，再回到现实使用同一构件的顶板跨过断桥。只允许从两座固定镜门换侧，镜面装饰本身不是可点击道路。

本关建立两个有限空间，不依赖实时反射。镜门内用楼梯/道路纹样提示另一侧结构，青绿浅水、阶地和大型镜框构成新剪影；现实用暖石、圆环符号，镜内用蓝白石、菱形符号及文字标识。

## 状态与坐标

状态为 `{ realm: real | mirror, shifted: false | true }`。下表为现实坐标；镜内映射为 `[x,y,-z]`。M0/M1 都在 z=0，跨门时人物落脚点不动。构件也使用相同映射，不能只换建筑颜色。

| 节点 | 坐标 | 用途 |
| --- | --- | --- |
| S | [-5,0,0] | 现实入口 |
| M0 | [-1,0,0] | 低位镜门 I，两侧固定落脚点 |
| T | [-3,3,-4] | 镜内楼梯顶点，路径内部节点 |
| W | [-5,3,-4] | 镜内外廊转角，路径内部节点 |
| V | [-5,3,-0.7] | 镜内外廊转角，路径内部节点 |
| C | [-2.5,3,-0.7] | 镜内侧廊把手，两个构件状态均可到达 |
| M1 | [1,3,0] | 高位镜门 II，两侧固定落脚点 |
| R | [1,5,-2] | 现实上层阶梯顶端、桥头 |
| Z | [1,5,-4] | 现实出口桥头 |
| E | [3,5,-4] | 现实光门 |

可停留目标 S/M0/C/M1/R/Z/E；两侧仅展示和拾取本侧实际路面。T/W/V 不作为停留目标。可穿镜的节点仅 M0/M1，可平移构件的节点仅镜内 C。

## 完整边表与几何

现实固定边 S–M0、M1–R、Z–E；shifted=true 时增加 R–Z。现实 M0 后只保留残阶装饰，不生成可行走的 M0–T 道路。

镜内固定边 M0–T、T–W、W–V、V–C；shifted=true 时增加 C–M1。镜内没有 R/Z/E 的路面或终点。外廊绕至楼梯左侧，避免其顶板在镜头中盖住低位人物与整段楼梯；C 退离屏风端面，保留操作时的人物轮廓。

L 形构件为刚体，竖直屏风中心 x=0、y=4，厚 0.18、高 2、沿 z 宽 2；水平顶板中心 x=1、顶面 y=5，沿 x/z 均长 2。初始 z=0，平移后现实 z=-3、镜内 z=3。镜内初始屏风横挡 C–M1，移开后该路开放；现实顶板移到 z=-3，恰好搭接 R(z=-2) 和 Z(z=-4)。屏风在桥侧 x=0，不挡 x=1 的行走线。现实高台位于远侧，避免前景高柱遮住低位镜门。

M0–T 上升 3，共 19 级；M1–R 上升 2，共 13 级。几何踏步和人物高度使用同一分级规则。构件操作时玩家停在侧廊 C，不站在运动顶板上；不增加搭乘或任意拖动机制。

## 动作与过渡

- `mirror`：仅 idle 且在 M0/M1。0.75 秒过渡，画布淡出/淡入，在中点更换显示空间，到末尾一次提交 realm。M0/M1 世界位置相同，朝向沿 z 反射；过渡期间不接受移动、再次穿镜或平移。
- `slide`：仅 idle、realm=mirror 且在 C。1 秒平移，构件连续移动，到位后提交 shifted 与两侧道路。重复操作可撤回，无隐藏一次性开关。
- 减少动态效果：穿镜 0.12 秒，平移 0.15 秒；仍保留输入锁定和到位提交。
- 重置取消所有过渡，返回 S/现实/初始构件；换关释放两侧几何、材质、纹样贴图。没有账号、联网或本地进度新增。

## 标准解与恢复

1. S → M0，穿镜进入镜内。
2. M0 → T → W → V → C，完整楼梯只在镜内存在。
3. 在 C 平移构件，屏风让开高位镜门。
4. C → M1，穿镜返回现实高台。
5. M1 → R → Z → E，走过刚刚准备好的顶板。

必要动作至少两次穿镜、一次平移。只往返低位镜门不能上现实高台；只切换空间不操作构件无法打开 C–M1；镜内没有可直接通关的 E。

误操作可恢复：C 收回构件后仍可到 M0；M1 从现实回镜内后可回 C 或 M0；现实 R 可以回 M1，Z 可以经顶板回 R。构件仅能在 C 操作，不能在有人站上顶板时抽走脚下道路。所有可达稳定状态必须有不依赖重置的通关路径。

提示逐级展开：观察完整楼梯、理解两座镜门高度差、解释构件两侧用途，最后给出当前位置的下一步。默认不一次列出解法。

## 验收

1. 标准解、必要穿镜和平移、全稳定状态可恢复、错误操作不提交；镜内 E 不可达。
2. 两座镜门均可往返，构件位置跨门保留；过渡中位置/状态/输入锁定正确，方向反射两次恢复。
3. 平移与穿镜中途重置、换关；减少动态效果；两侧可见模型和碰撞目标一致，隐藏一侧不能挡点击。
4. Chrome/Edge 鼠标通关、回程、多视口、DPR 2、建筑与控制区避让；检查楼梯、屏风、顶板实际几何和人物脚下位置。
5. 旧七关回归、资源释放、构建与外网隔离。Mac 真机和免 Node 玩家包继续暂缓。
6. 趣味性和玩家能否理解两个空间的互补关系仍需试玩，不以自动通关替代。

# jlbg：浏览器空间解谜游戏

以《纪念碑谷》的空间解谜方式为主要参考，开发本地浏览器可玩的原创游戏。最终目标覆盖 Windows 和 macOS；现阶段优先继续做关卡，Mac 工作暂缓。

**当前可玩：三关完整篇章。** 第一关「回光庭院」学习转桥；第二关「浮阶之塔」搭乘升降塔，再借侧廊通行；第三关「借光回廊」组合灯台压板、门与转桥。三关均可通关、重玩，并通过本机 Chrome/Edge 验证。现有布局保留，只补必要的章节与机关入口。

## 本地开发与验证

在已安装依赖的项目目录运行：

```powershell
npm run dev
```

打开终端显示的本地地址。右上角可直接选择任意一关；点击道路让旅人移动，站稳在圆形控制台后操作机关。第二关也可站在塔顶升降。第三关分别点击转桥和移灯按钮。动画中可用「重新开始」重置，通关后可进入下一关或重玩。

```powershell
npm test
npm run build
npm run preview
```

测试使用 Node 内置测试器；build 输出到 dist，preview 用于本机检查构建。当前开发/预览仍需本机 Node 与已安装依赖；面向玩家的免开发依赖包尚未提供。构建保留旧产物，正式发包前需核对版本文件清单。

# jlbg：浏览器空间解谜游戏

以《纪念碑谷》的空间解谜方式为主要参考，开发本地浏览器可玩的原创游戏。最终目标覆盖 Windows 和 macOS；现阶段优先继续做关卡，Mac 工作暂缓。

**当前可玩：六关。** 前三关保留为入门篇；第四关「双环庭院」改变桥环的联动关系，第五关「借身之塔」搭乘石偶并建立独立归路，第六关「归光天穹」组合锁桥、搭乘与道路规划。新章使用灰紫与浅粉建筑；机关按钮集中在画布之外的底部操作区，主动查看分级解题提示。

## 本地开发与验证

在已安装依赖的项目目录运行：

```powershell
npm.cmd run dev
```

打开终端显示的本地地址。右上角可直接选择六关中的任意一关；点击道路让旅人移动，站稳在圆形控制台后操作底部机关按钮。虚线按钮表示当前条件不满足，点击会解释原因。第二关可站在塔顶升降，第五、六关可站上石偶搭乘。第四关起，解题提示由「查看提示」主动逐级展开。动画中可用「重新开始」重置，通关后可进入下一关或重玩。

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

以上为 Windows PowerShell 命令，使用 npm.cmd 避免 npm.ps1 的执行策略限制。测试使用 Node 内置测试器；build 输出到 dist，preview 用于本机检查构建。当前开发/预览仍需本机 Node 与已安装依赖；面向玩家的免开发依赖包尚未提供。构建保留旧产物，正式发包前需核对版本文件清单。

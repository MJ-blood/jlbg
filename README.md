# jlbg：浏览器空间解谜游戏

以《纪念碑谷》的空间解谜方式为主要参考，开发本地浏览器可玩的原创游戏。最终目标覆盖 Windows 和 macOS；现阶段优先继续做关卡，Mac 工作暂缓。

**当前可玩：第一至第十二关。** 前三关是入门篇；第四至六关组合桥环、石偶、压板与道路规划；第七至十一关依次加入双视角、镜内外空间、建筑折页、双角色协作，以及镜门与折页组合；第十二关用三幕互助流程完成终章。

第七关「换景之庭」使用离散视角寻找投影道路；第八关「镜海回廊」在现实与镜内准备同一构件；第九关「折页之城」让建筑绕真实铰链改变正反面；第十关「同行之桥」交替控制旅人与岩灵；第十一关「镜中折院」组合镜门和折页；第十二关「归海之门」要求先到的旅人为岩灵固定最后一桥。整体设计见 [新篇章方案](docs/levels-07-12-proposal.md)。

六关已统一采用精修风格：旅人具有衣袍、帽檐、手脚与步态，建筑增加立体拱窗、分层台座和机关细节；升降塔、灯笼、双环和石偶保留各自特色。玩法不变，六关已通过浏览器通关与构建资源隔离验证，具体范围见 [六关视觉验证记录](docs/validation-visual-six.md)。

## 本地开发与验证

在已安装依赖的项目目录运行：

```powershell
npm.cmd run dev
```

打开终端显示的本地地址。右上角可直接选择十二关中的任意一关；点击道路让角色移动，站稳在固定平台后操作底部机关按钮。虚线按钮表示当前条件不满足，点击会解释原因。第十关可切换旅人与岩灵，第十一关需要在镜内和现实分别利用折页。系统设置减少动态效果时使用短切换。第四关起，解题提示由「查看提示」主动逐级展开。动画中可用「重新开始」重置，通关后可进入下一关或重玩。

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

以上为 Windows PowerShell 命令，使用 npm.cmd 避免 npm.ps1 的执行策略限制。测试使用 Node 内置测试器；build 输出到 dist，preview 用于本机检查构建。当前开发/预览仍需本机 Node 与已安装依赖；面向玩家的免开发依赖包尚未提供。构建保留旧产物，正式发包前需核对版本文件清单。
